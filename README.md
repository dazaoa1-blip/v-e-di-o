# 独立游戏视频 EP04 · 素材仓

本仓库存放《独游视频》EP04 制作所需的音频素材、预览版，以及配好口播的正式成片。

| 路径 | 内容 | 大小 |
| --- | --- | --- |

| `成片/EP04_口播校对稿.txt` | 8 段录音的逐句校对稿 | — |

## 正式成片（口播版）

`成片/EP04_打击感_成片.mp4`：1920×1080 / 60fps，时长约 7 分 41 秒。

- **以录音为准**：8 段口播按顺序铺满全片，字幕逐句按录音内容重写，并对齐到实际说话时间；
  预览版里烧录的旧字幕已被同款字幕框覆盖替换。
- **画面跟着口播走**：每个画面段落对应口播里的那句话，按口播长度做了 0.7–1.3 倍的变速；
  录音里没讲到的画面（如“不是标准答案”“放回去自己试”“你的项目哪一下最软”）已剪掉，
  章节转场卡和无口播的“完整前后回放”保留原速。
- **声音**：口播做了降噪/压缩，响度约 -16 LUFS；《糖果物语》全程循环垫底，
  说话时自动压低约 4 dB、停顿和转场时回升，保证始终听得见；预览版自带的打击音效保留并随画面变速。
